04

Download

One input file produces one .asset and one intermediate .txt.

Import into Unity

  1. Copy the generated .asset into Assets/Resources/Scriptables/Dialogues/<Arc>/.
  2. Let Unity compile, then run the portrait tool to fill sprites.
  3. Wire nextDialogue / nextSceneName in the Inspector if you are chaining dialogues.

No .meta file is produced — Unity generates it on import.
